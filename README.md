# Manajemen-Parkir-Gedung
repositori ini adalah hasil dari studi kasus tugas besar struktur data kelompok bersiaplah IF-49-11. Pengelola gedung membagi lahan parkir menjadi beberapa area, dan setiap kendaraan yang sedang parkir hanya berada di satu area. Tiket parkir dicatat untuk pencarian dan perhitungan tarif
